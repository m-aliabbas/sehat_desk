Reception

A patient joins the doctor's queue only once every fee paid at reception is paid. Emergencies go first and pay later.

{% include "components/field.html" with field=form.consultation_fee_billed_at %} {% if form.reception_prints_blank_rx %}{% include "components/field.html" with field=form.reception_prints_blank_rx %}{% endif %}

Other fees (injection, dressing...) are routed per service: Settings → Clinical lists → Services → "Fee is paid at".

Doctor, lab and pharmacy

After the doctor, a patient with tests to give goes to the lab first, then to the pharmacy if medicine or a pharmacy fee is waiting.

{% include "components/field.html" with field=form.lab_tests_billed_at %} {% include "components/field.html" with field=form.doctor_must_click_next %} {% include "components/field.html" with field=form.doctor_generates_digital_rx %} {% include "components/field.html" with field=form.rx_print_at %} {% include "components/field.html" with field=form.pharmacy_handles_manual_rx %}

The lab does not work on an OPD patient while any lab fee is unpaid, wherever it is paid. Urgent and STAT orders can be collected with a written reason; emergencies are never held.
